# 每日复盘模板（Markdown 次选）

> **输出优先级**：首选生成 **HTML 单文件报告**（见 @daily-report.html.md 与 @../references/08-output-format.md）；  
> 仅当无法交付 HTML 时使用本 Markdown 骨架。两种格式章节完整度相同。  
> 使用说明：收盘后 1–2 小时内填写。数据不足用降级话术，禁止编造。  
> 颜色：涨红 `#ef232a`，跌绿 `#14b143`。
