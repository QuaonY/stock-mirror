## 开仓五条件核对（下单前逐条打勾）

- [ ] 1. 账户熔断未触发
- [ ] 2. 风格明确且 L4 已按该风格校准
- [ ] 3. 技术信号 ≥ B，且非反向信号并存
- [ ] 4. 首仓% 过公式且 ≤ 单票/单板块上限
- [ ] 5. 清单已写：止损、加仓、止盈、最差情景与证伪条件

## 仓位公式备忘

```
止损距离% = (买入价 - 止损价) / 买入价 × 100
首仓% = min(信号参考仓位%, 单票上限%, 单笔风险上限% / 止损距离%)
```

示例：单笔风险上限 1%，买入 10.00，止损 9.40 → 距离 6% → 首仓 ≈ 16.7%
