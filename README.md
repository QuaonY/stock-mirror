# StockMirror · 股海镜鉴

> 以市场为镜，鉴往知来。

StockMirror 是一个面向 A 股分析场景的 AI Skill，帮助 Agent 按统一流程完成行情核验、每日复盘、选股分析、交易计划和风险检查。

| 许可证 | [MIT](LICENSE) |

## 安装

### 推荐方式：把仓库链接发给 AI

在支持 Skill 的 Agent 软件中，打开对话并发送[项目仓库链接](https://github.com/QuaonY/stock-mirror)，告诉 Agent 按仓库说明安装。可以直接使用下面这段提示词：

> 请阅读这个仓库的 README.md 和 SKILL.md，并为当前 Agent 安装 StockMirror Skill。优先使用仓库 Releases 中最新的 `StockMirror.zip`；如果 Release 包不可用，再从仓库文件安装。请先确认当前 Agent 的 Skill 安装目录，安装前告诉我将写入的位置和文件范围；不要运行仓库里的脚本，也不要改动其他项目文件。完成后告诉我如何启用和调用这个 Skill。如果你无法访问仓库、Release 包或本地安装目录，请说明需要我手动完成的步骤，不要猜测路径。

Agent 软件需要能够访问仓库内容并支持安装 Skill。不同软件的 Skill 目录和导入方式不同，按宿主软件实际支持的方式安装。若 AI 无法访问 GitHub 或没有本地文件写入权限，可手动从仓库 Releases 下载作者发布的最新版 `StockMirror.zip`，再按 Agent 软件的说明导入。

### 安装后确认

安装完成后，可让 Agent 确认已加载 `stock-mirror` Skill。若宿主软件要求新开会话或重新加载 Skill，按提示操作。

## 配置行情 MCP

Skill 不自带行情接口，也不会替用户连接 MCP。若要进行实时行情分析，请先在 Agent 软件的 MCP / 工具设置中连接金融行情数据源；工具由宿主 Agent 提供。

推荐至少配置 **2 个相互独立的行情来源**，并至少包含 1 个主要来源（例如同花顺 iFinD、通达信或东方财富妙想，具体是否可用取决于宿主软件提供的 MCP）。

| 模式 | 数据条件 | 行为 |
|---|---|---|
| **A · MCP 互验** | 至少 2 个已探活且相互独立的行情源，至少 1 个为主要来源 | 关键数据交叉验证后再给出分析 |
| **B · 单源降级** | 仅有 1 个有效的主要行情源 | 明确提示可信度受限，只给候选或观察内容，不给开仓许可 |
| **C · 弱源降级** | 没有有效探活证据、仅有弱源或没有主要来源 | 明确提示风险，不生成买入清单或开仓许可 |

如果 Agent 没有发现可用的金融行情 MCP，会提示你去宿主软件连接，或由你明确选择弱源降级继续。普通网页搜索、网络可访问或工具名称匹配，都不代表行情 MCP 已成功连接；若宿主不向 Agent 展示工具清单，Agent 会说明无法核实，而不会断言未连接。

## 触发方式

安装后通常不需要固定斜杠命令。直接在 Agent 对话中用自然语言提出需求即可；也可以在请求中点名 **StockMirror** 或 **stock-mirror**，帮助宿主 Agent 选择对应 Skill。

### 每日复盘

> 使用 StockMirror，帮我复盘今天的 A 股市场。先检查可用行情数据源，标注数据时间和来源；按大盘、板块、个股和风险流程分析，缺失数据请明确说明。

### 盘前计划

> 调用 StockMirror，为下一个交易日制定 A 股盘前计划。先核验行情 MCP 和数据时效，再整理市场环境、主线候选、观察标的、触发条件和风险点。

### 选股与个股诊断

> 用 StockMirror 按我的短线风格分析这几只股票：[股票代码列表]。说明数据来源、筛选理由、关键风险和失效条件；没有可靠数据时不要猜测。

### 仓位与风控

> 使用 StockMirror 检查我的仓位和交易计划：[填写持仓、账户风险上限、计划止损等必要信息]。先检查账户熔断和开仓条件，再说明仓位计算依据；信息不足时先列出缺少的内容。

也可以直接提出“分析某股票的技术面”“评估某公司的护城河和估值”“做本周市场全景复盘”等请求。请提供分析所需的日期、股票代码、投资周期或账户约束；不必提供密码、API 密钥等凭证。

## StockMirror 如何工作

```text
行情与数据核验 → 宏观与大盘 → 板块主线 → 个股筛选
               → 短线 / 波段 / 长线分析 → 仓位与风险检查
```

- **每日闭环**：宏观定势、大盘看势、板块找主线、个股精选、心态纪律、策略执行。
- **选股漏斗**：流动性筛选、策略初筛、技术共振、按投资风格校准。
- **风险优先**：检查开仓条件、仓位、账户熔断和报告质量；关键门禁未通过时不提供开仓许可。
- **如实表达**：数据缺失时留空并说明，来源冲突时降级，不编造行情或结论。
- **报告格式**：复盘优先使用可离线查看的单文件 HTML；必要时使用结构完整的 Markdown。
