# 05 · 仓位与风控

## 5.1 总仓位闸门（由大盘+情绪决定）

| 市场状态 | 总仓位建议 | 备注 |
|----------|-----------|------|
| 放量上攻 + 情绪发酵 | 70–100% | 仍留机动 |
| 结构性震荡 | 40–70% | 只做主线 |
| 缩量阴跌 / 退潮 | 20–40% | 防御为主 |
| 系统性风险 / 冰点未确认 | 0–20% | 空仓也是仓位 |

> 以上为分析框架中的参考区间，需按个人风险承受力收紧，不可机械套用。

## 5.2 个股与板块约束

| 约束 | 建议上限 |
|------|---------|
| 单票 | 账户 15–20%（短线可更严 10%） |
| 单一板块 | 账户 30–40% |
| 关联持仓（同一逻辑） | 视作一个板块计算 |
| 单笔风险（到止损） | 账户 0.5–1.5% |

## 5.3 仓位计算公式（强制）

S/A/B/C 参考仓位是**上限**，实际首仓不得超过按风险反推的仓位：

```
止损距离% = (买入价 - 止损价) / 买入价 × 100
首仓% = min(信号参考仓位%, 单票上限%, 单笔风险上限% / 止损距离%)
```

**示例**：账户单笔风险上限 1%，买入价 10.00，动态止损 9.40 → 止损距离 6% → 首仓上限 = 1%/6% ≈ **16.7%**。若信号为 S（参考 20%），仍取 16.7%。

止损距离过宽（如 >12%）导致计算仓位过低时：**放弃或等更好买点**，禁止为凑仓位而放宽止损。

## 5.4 开仓五条件（硬门槛，缺一不可）

任何买入（含 S 级）必须同时满足，否则只能进观察池：

| # | 条件 | 不满足则 |
|---|------|----------|
| 1 | 账户熔断未触发 | 禁止新开仓 |
| 2 | 属于当日主线 / 明确交易风格，且 L4 已按该风格校准 | 不得混用校准路径 |
| 3 | 技术信号 ≥ B（S/A/B），且非反向信号并存 | 见下 |
| 4 | 首仓 % 过公式且 ≤ 单票/单板块上限 | 减仓或放弃 |
| 5 | 盘前清单已写：止损、加仓、止盈、最差情景与证伪条件 | 不下单 |

**反向信号并存处理**：
- 趋势类（trend / GMMA 多头 / 云上）与反转类（low_position / bollinger 下轨 / macd 底背离）**不得进入同一笔计划**。
- 先按工作流定风格：短线偏情绪与趋势确认，波段偏趋势，长线偏价值与反转中的优质票；再选 1 条策略族。
- SCORE 只用于**排序扩池**，**不能单独作为开仓充分条件**。

## 5.5 账户级熔断与总风险预算

在单笔/单票约束之外，必须有账户层硬规则：

| 条件 | 强制动作 |
|------|----------|
| 账户回撤 ≥ 8%（相对阶段峰值净值） | 总仓位减半，显式记录保护期截止日后停止新开仓 |
| 账户回撤 ≥ 12% | 停止新开仓 ≥ 1 周；只保留核心仓或清零观望 |
| 连续 3 笔止损 | 当日停止开仓；复盘是否风格与市场错配 |
| 单月亏损 ≥ 10% | 当月剩余时间总仓位 ≤ 30%；周末强制周复盘 |
| 单周亏损 ≥ 6% | 下一周总仓位上限降一档（如 70%→40%） |

**月度复位**：每月首个交易日完成复盘后，由操作者显式运行 `circuit_breaker.py --reset-month`，重置月度亏损与连续止损计数；脚本不会自行推断交易日或自动复位。若仍处回撤保护期，不自动恢复满仓权限，需连续 5 个交易日净值企稳才逐档恢复。保护期使用 `--halt-until YYYY-MM-DD` 显式记录截止日，不以自然日近似交易日。

**总风险预算**：单月理论最大亏损 ≈ 单笔风险% × 当月可交易笔数 × 执行率；若该值 > 8%，说明频率或单笔风险过高，须下调。

## 5.6 止损止盈纪律

```
入场前必须写清:
  止损价 / 逻辑失效价 / 第一目标 / 第二目标

执行:
  触发止损 → 当日或次日开盘无条件减仓/清仓
  触发止盈 → 分批，不追求卖在最高
  逻辑证伪（业绩、政策、龙头卡位失败）→ 不等止损位
```

### 5.6.1 涨跌停 / T+1 极限场景（一字跌停出不去时）

A 股 T+1 + 涨跌停可能导致「该止损却无法成交」。预案如下：

| 场景 | 动作 |
|------|------|
| 跌停打开、流动性恢复 | **立即按计划市价/对手价减仓或清仓**，不等反弹「回本」 |
| 全天一字跌停 / 封死无法成交 | 记入「无法执行止损」；**次日集合竞价优先出**，开盘继续封死则继续挂 |
| 持仓已触发熔断或单笔风险超限 | 未出清前：**禁止加仓摊薄、禁止抄底、禁止换仓到同板块跟风** |
| 连续 2 日无法按止损价出清 | 降为「强制清仓名单」，第三日只要开板/放量必须出；并触发连亏复盘 |
| 打板/排板买入 | 首仓上限再降一档（如 10%→5%）；炸板未回封的票**不得计入「今日有效持仓」加仓计划** |

**纪律口径**：一字跌停导致的滑点与无法成交，计入绩效（滑点 + 实际成交价），**不得从样本中剔除**。

## 5.8 回测与绩效闭环（检验体系是否有效）

记录不是终点，必须定期检验策略与体系本身。

| 周期 | 动作 |
|------|------|
| 每笔平仓后 | 记录：标的、逻辑、信号级、持仓天数、毛利/净利（扣成本）、是否按纪律执行 |
| 每周 | 胜率、盈亏比、最大单笔亏损、止损执行率；与「完全按清单执行」子集对比 |
| 每月 | 净值 vs 基准（沪深300 / 中证1000 / 万得全A，按风格选 1 个主基准）；超额收益与回撤 |
| 每季 | 策略池回顾：各策略命中率、S/A 信号后 N 日收益、C 级误判率；淘汰连续两季跑输基准且逻辑过时的策略 |
| 建议 | 新规则先小仓位/模拟 ≥ 4 周再进正式仓位；避免在牛市单边样本上过度拟合 |

**绩效不达标定义（触发降频或停用）**：
- **短线**：扣费后连续 3 周跑输主基准，或连续 2 周净亏损 → 下一周强制降频/减仓验证
- **波段/长线**：扣费后连续 8 周跑输主基准 且 胜率 < 40% 且 盈亏比 < 1.5
- 止损执行率 < 80%（先修纪律，再修策略）；一字跌停导致的无法成交单独统计，不从样本剔除
- 样本 < 20 笔时不下「策略无效」结论，只标「证据不足」
