# 04 · 三条工作流（短线 / 波段 / 长线）

## 工作流 A · 日内 / 短线（T+1 ~ 数日）

```
盘后:
  1. 六步复盘 + 盘前规划
  2. 短线概率（可选）+ 大佬圆桌仅作辅助
  3. 对候选技术快诊（GMMA+云层+ADX）
  4. L4 走「短线分流」：跳过 DCF/护城河，只做主线+地位+止损距离
盘中:
  5. 只执行清单；开仓先过五条件；破止损走（含一字跌停预案）；情绪冰点不接力
```

| 要点 | 标准 |
|------|------|
| 主战场 | 主线龙头、辨识度高的涨停梯队 |
| 仓位 | 单票 ≤10–15%，总仓位随情绪周期伸缩 |
| 买点 | 分歧转一致、回踩关键均线、弱转强 |
| 卖点 | 高潮兑现、断板、跌破 5 日线 / 动态止损 |

## 工作流 B · 中线波段（数周 ~ 数月）

```
每周 / 每调仓:
  1. 多策略 AND/SCORE 初筛候选池
  2. 技术面诊断 + 动态止损
  3. 多周期预测 + 体制感知校准
  4. 每日跟踪主线与持仓
```

| 要点 | 标准 |
|------|------|
| 主战场 | 产业趋势 + 业绩兑现的行业龙头/中军 |
| 持仓 | 5–10 只，单票 ≤15–20% |
| 买点 | 趋势确认后的缩量回踩、平台突破 |
| 卖点 | 趋势破坏（破 60 日线/云层下轨）、逻辑证伪 |

## 工作流 C · 长线价值（1 年+）

```
建仓前:
  1. 十分钟测试 → 过关才继续
  2. 五维深析 + DCF + 安全边际
  3. 体制感知 + 宏观情景校准
持有中:
  4. 跟踪估值与基本面变化
  5. 财报季更新假设
```

| 要点 | 标准 |
|------|------|
| 主战场 | 宽护城河 + 可理解的商业模式 |
| 持仓 | 3–8 只，深度研究后重仓仍受单票上限约束 |
| 买点 | 安全边际足够时分批 |
| 卖点 | 护城河侵蚀、估值严重透支、更好机会成本 |

## 工作流 D · 自上而下全景（每周一次）

```
1. 自上而下：宏观体制 → 受益板块 → 指数健康 → 仓位倾向
2. 板块相对强度（RPS）
3. 全策略综合排序（score mode）
4. 对拟长持标的做深度价值分析
```

## 技术诊断速查（GMMA + 一目均衡 + ADX）

### 前置硬门槛

- 20 日均成交额 ≥ 1 亿，否则 REJECT
- 默认剔除 688 科创、8 开头北交

### 评分表（满分 100）

| 条件 | 分值 |
|------|------|
| GMMA 多头排列（短组 > 长组） | +25 |
| GMMA 离散度 > 2% | +10 |
| 价格在云层上方 | +20 |
| 转换线 > 基准线 | +10 |
| TK 金叉 | +5 |
| 云层厚度 > 3% | +5 |
| ADX > 40 | +20 |
| ADX 30–40 | +15 |
| ADX 20–30 | +10 |
| 成交额 > 10 亿 | +5 |

### 信号分级与操作

| 信号 | 分数 | 参考仓位上限 | 操作 |
|------|------|--------------|------|
| S | 90+ | 20% | 强烈关注，可按计划买 |

### 动态止损

```
止损位 = max(云层下轨, 60EMA)
风险% = (现价 - 止损位) / 现价 × 100
```

若单笔风险 > 账户可承受上限，减仓或放弃。

## DCF 速查（仅长线）

```
自由现金流 FCF = 经营现金流 - 资本支出
增长率 g = min(历史平均, 行业平均)；永续 g 常取 2.5–3%（衰退 2%）
折现率 R 基准 10.5%（A 股常用区间 10–12%）
  小市值 +1–2%  高杠杆 +1–2%  周期 +1–2%
  强护城河稳定可 9–10%  高风险 13–15%
A 股特有折价（在 R 或终值中体现，勿重复计）：
  公司治理/信息披露折价  +0.5–1.5%
  流动性折价（小盘/低换手） +0.5–1.5%
  政策与监管不确定性     +0.5–1%（视行业）
永续价值 = FCF10 × (1+g) / (R-g)
内在价值/股 = (Σ FCF现值 + 永续现值 + 净现金) / 总股本
安全边际 = (内在价值 - 现价) / 内在价值
```

> **注意**：A 股直接套美股折现率/永续增长会系统性偏乐观。优先「提高 R」或「下调中期 g」，并在结论中写明采用了哪些折价。
