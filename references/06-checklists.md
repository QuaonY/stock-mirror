## 6.1 每日复盘检查清单

- [ ] **MCP 检查**：已连接行情 MCP 数量 N=？是否 ≥2？文首是否写明模式 A/B/C？
- [ ] 模式 B/C：是否已输出对应数据风险/降级提示，并引导用户连接 MCP？
- [ ] 步骤 0：关键数据是否互验（≥2 源一致）？每条数据是否做过准确性校验？
- [ ] 缺失字段：是否强制留空并写提示（禁止编造/估算）？
- [ ] 用户画像：是否读取 `state/user_risk_profile.json`？
- [ ] 宏观：今日最重要的 1–2 条消息？如何传导？
- [ ] 大盘：指数谁强？量能环比？情绪阶段（对照步骤2 + 本机校准表）？
- [ ] 板块：主力流入 TOP？连板高度？主线是谁？阶段？（北向仅数据可得时）
- [ ] 个股：风格是否明确？L4 是否按风格分流（短线不套 DCF）？
- [ ] 个股：技术分 + 止损 + 公式首仓% + 最差情景/证伪 是否写全？
- [ ] 风控：熔断状态？开仓五条件是否全部通过？
- [ ] 心态：今日有无情绪化单？计划外交易？
- [ ] 策略：明日买入/卖出/观察三张清单是否写完（含一字跌停预案）？
- [ ] 五维总结 + 一句格言
