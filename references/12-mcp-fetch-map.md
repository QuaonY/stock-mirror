# 12 · MCP 取数字段映射（Fetch Contract）

> 用途：告诉 Agent「去哪个源、拉什么字段、怎么算派生指标」。  
> 不替代具体 MCP 工具名——宿主环境工具名可能不同，按语义匹配即可。

## 12.1 通用约定

| 约定 | 说明 |
|------|------|
| 交易日 | 以交易所日历为准；非交易日不拉「当日」涨跌停 |
| 时间戳 | 优先收盘后快照；盘中数据必须标「盘中，非收盘」 |
| 复权 | 技术分析默认前复权；财务另注明 |
| 单位 | 成交额统一「亿元」；资金净流入统一「亿元」 |
| 失败 | 字段写 `【缺失】`，禁止用前一日冒充 |

## 12.2 字段 → 源优先级 → 派生

### A. 大盘指数（步骤2 必拉）

| 字段 | 主源 | 备源 | 派生/校验 |
|------|------|------|-----------|
| 上证/深证/创业板/科创50 收盘、涨跌幅 | 通达信 / iFinD / 万得 | 东财、腾讯自选股 | 双源差 <0.1% |
| 两市成交额（亿） | 东财 / iFinD | 通达信 | vs 5日/20日均额 → 放量/缩量 |
| 涨跌家数 | 东财 / 通达信 | 同花顺 | 涨跌比 |

### B. 情绪与涨停结构（步骤2/3 必拉）

| 字段 | 主源 | 备源 | 派生 |
|------|------|------|------|
| 涨停家数、跌停家数 | 东财 | 同花顺、涨停工具 | 对照校准表 P 分位 |
| 最高连板、连板梯队 | 东财 | 同花顺 | 情绪高度 |
| 炸板率 | 东财/涨停工具 | 同花顺 | `(盘中触及-收盘封板)/触及` |
| 首板/2连/3连+ 数量 | 东财 | 同花顺 | 启动质量 |

### C. 板块与资金（步骤3 必拉）

| 字段 | 主源 | 备源 | 派生 |
|------|------|------|------|
| 行业/概念主力净流入 TOP | 东财妙想 | iFinD、万得 | 标口径（东财/同花顺）不混用 |
| 涨停所属板块分布 | 东财 | 同花顺 | 主线占比 |
| 南向资金（港股联动时） | 东财/万得 | — | 可选 |
| 北向 | 见数据基建 | — | 实时不可得则跳过 |

### D. 个股（步骤4，持仓+主线候选）

| 字段 | 主源 | 备源 | 派生 |
|------|------|------|------|
| OHLCV、均线 | 通达信 / iFinD | Tushare、腾讯 | GMMA 短/长组 |
| 一目均衡（转换/基准/云带） | 通达信指标 | 自算 | 价与云关系、止损=max(云下,60EMA) |
| ADX | 通达信 / iFinD | 自算 | 20/30/40 分档 |
| 20日均成交额 | 同上 | Tushare | ≥1亿 硬门槛 |
| 基本面快检（ROE/增速） | Tushare / 万得 | iFinD | 长线才深挖 |

### E. 宏观消息（步骤1）

| 字段 | 主源 | 备源 | 规则 |
|------|------|------|------|
| 央行/LPR/财政 | 央行、财政部、统计局官网 | 财联社 | 以官方原文为准 |
| 海外指数/汇率/大宗 | 万得 | 雅虎、英为 | 注明时区 |
| 产业政策 | 部委官网 | 证券时报 | 媒体仅线索 |

## 12.3 伪代码：一次标准拉数

```text
1. mcp_health → mode
2. 拉指数收盘 + 成交额（≥2源或标单源）
3. 拉涨停结构 + 主力净流入
4. 对持仓/候选：
     - OHLCV + ADX + 均线 → tech_score.py
     - 云下轨/60EMA → 动态止损
     - position_calc.py → 首仓% + 五条件
5. 缺失字段一律【缺失】
6. 写 audit-log
```
