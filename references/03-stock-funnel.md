# 03 · 选股漏斗：从市场到个股

```
全市场 A股约5000+
  → L1 流动性（20日均额≥1亿）
  → L2 策略初筛（11策略，AND最严 / SCORE综合）
  → L3 技术共振（GMMA+云层+ADX，S/A/B/C）
  → L4 价值/预测（按风格分流校准）
  → 核心池 5–15 只 + 持仓跟踪池
```

## L1 流动性过滤

- 20 日均成交额 ≥ 1 亿（可调）
- 剔除 ST、退市风险、长期停牌
- 默认可剔除科创板/北交（按策略需要保留）

## L2 策略初筛

### 按风格推荐策略

| 风格 | 推荐策略 | 核心条件 |
|------|---------|---------|
| 质量成长 | `growth` + `roe` | 营收/净利双增 ≥20%；ROE≥15% |
| 价值低估 | `valuation` + `dividend` | PE≤25、PB≤3、PEG≤1.5；股息≥3% |
| 趋势动量 | `trend` + `volume_surge` | 均线多头、R²≥0.5、ADX≥25；放量≥2x |
| 反转抄底 | `macd` + `low_position` + `bollinger` | 底背离 / 价格分位≤25% / 布林下轨 |
| 筹码质量 | `shareholder_concentration` + `cashflow_quality` | 户数降；经营现金流≥净利润 |

### 组合模式选择

| 模式 | 含义 | 适用 |
|------|------|------|
| **AND** | 必须同时通过 | 精选、严标准 |
| **OR** | 任一通过即入选 | 扩池、找线索 |
| **SCORE** | 全策略打分排序 | 综合排序、主入口 |

**推荐默认**：全策略 + SCORE + top 50，再人工砍到 15 以内。

### 选股策略速查（11+1）

| ID | 一句话条件 |
|----|-----------|
| roe | ROE≥15%，ROA≥5% |
| macd | 价下行 + MACD 上行 + 底背离 + 放量 |
| dividend | 股息≥3%，连分 3 年，ROE≥8% |
| valuation | PE≤25，PB≤3，PEG≤1.5，ROE≥8% |
| growth | 营收/净利双增≥20%，毛利≥30% |
| low_position | 价格分位≤25%，RSI≤40 |
| volume_surge | 放量≥2×，RSI≤45，反弹≥3% |
| trend | 均线多头 + R²≥0.5 + ADX≥25 |
| pattern | 双底/吞没/早晨之星等 |
| bollinger | 触及下轨 + RSI 超卖 |
| shareholder_concentration | 户数连降 3 期 + ROE≥8% |
| cashflow_quality | 经营现金流≥净利 3 期，商誉<30% |

## L3 技术共振

对 L2 候选逐只打分：
- 仅保留 **S / A / B**（C 直接丢弃）
- 记录动态止损与**止损距离%**
- B 级放入「观察池」，等突破确认再升 A/S

评分表与动态止损公式见 @02-daily-loop.md §4.3。

## L4 校准（按风格分流，禁止混用）

L4 **必须先定工作流风格**，再选校准路径。短线票硬套 DCF、长线票只看圆桌，均视为无效校准。

| 风格 | 必做 | 可选 | 禁止 |
|------|------|------|------|
| **短线 / 情绪票** | 流动性、主线归属、S/A/B、止损距离与仓位公式、板块地位/龙头辨识度、炸板/一字风险 | 短线方向概率仅作辅助 | **十分钟测试、DCF、护城河深度** |
| **波段 / 趋势** | 技术 S/A/B + 量价 + 业绩/催化是否可验证 | 多周期 1d/5d/1M；圆桌 | 仅凭圆桌满仓 |
| **长线 / 价值** | 十分钟测试 → 五维 → DCF + 安全边际 | 体制感知做情景 | **仅凭圆桌/概率分开仓** |

### 中短线校准要点

- 多周期：1d / 5d / 1M 方向 + 概率 + 共识度
- 体制感知：当前牛/熊/震荡下该票表现
- 大佬圆桌：多策略共识——**仅作信息，不作开仓充分条件**
- 评分 ≠ 盈利预测，只是历史相似条件上涨概率
- **强制反向字段**：最差情景 1 条 + 证伪条件（何时该走）

### 长线校准

**十分钟测试（9 问，全过才深度分析）**：

1. 是否持续赚取营业利润？
2. 经营活动是否持续产生现金流？
3. ROE 能否保持 10%+ 且杠杆合理？
4. 盈利增长是否协调一致？
5. 资产负债表是否干净？
6. 是否产生自由现金流？
7. 「其他」项占比是否过高？
8. 股本是否明显稀释？
9. 粗略 DCF 估值是否有吸引力？

**五维深度**（过测试后）：

| 维度 | 要点 |
|------|------|
| 护城河 | 历史盈利 5–10 年；来源：品牌/成本/转换成本/网络效应/壁垒；宽度 |
| 财务健康 | 六大危险信号：现金流衰退、非经常费用、连续收购、CFO离职、应收异常、赊销放宽 |
| 管理层 | 能力 / 诚信 / 股东导向 |
| 行业 | 生命周期 + 行业特定指标 + CR5 |
| 估值 | DCF + 安全边际 |

**安全边际要求**：

| 公司类型 | 要求 |
|----------|------|
| 强护城河稳定 | ≥20% |
| 一般公司 | 30–40% |
| 高风险/周期 | ≥60% 才考虑 |
