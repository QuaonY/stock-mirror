# 02 · 每日闭环：分析 → 复盘 → 规划

> 六步 SOP：**宏观 → 大盘 → 板块 → 个股 → 心态 → 策略**

## 步骤 1 · 宏观与消息面（定大势）

**目的**：界定当日大环境，决定进攻/防守基调。

| 维度 | 关注点 |
|------|--------|
| 政策面 | 央行 LPR/降准降息；财政国债节奏；产业（AI/低空/半导体/新能源）；监管动态 |
| 海外联动 | 美股三大指数、恒指、美元指数、USDCNY、10Y 美债/中债、原油/黄金/铜 |
| 传导路径 | 美股龙头（英伟达/苹果/特斯拉）→ A 股科技；中概 → 情绪；港股 → 常领先 |
| 热点评分 | 影响范围/持续时间/确定性/市场反应，各 1–5 分 → 综合分定优先级 |

**输出**：
- 大势定性：偏多 / 中性 / 偏空
- 主线候选方向 2–3 条
- 风险事件清单（必须规避或观察）

---

## 步骤 2 · 大盘与指数（看整体）

**目的**：判断市场强弱与风格（大小盘、价值/成长）。

**必看指标**：

| 类别 | 指标 | 解读 |
|------|------|------|
| 指数对比 | 上证 / 深证 / 创业板 / 科创50 / 北证50 | 谁强谁弱 → 风格 |
| 量价 | 成交额 vs 近 5/20 日均量 | 放量/缩量/平量 |
| 情绪 | 涨停数、跌停数、涨跌比、连板高度、炸板率 | 情绪周期位置 |
| 体制 | 牛/熊/震荡；波动率水平 | 仓位总闸门 |

**量价口诀**：

| 形态 | 含义 | 策略暗示 |
|------|------|---------|
| 上涨 + 量能不足 | 存量博弈震荡 | 不追高，低吸 |
| 放量突破 | 资金入场，趋势转强 | 可提高仓位 |
| 缩量下跌 | 抛压减轻，可能接近底部 | 观察企稳信号 |
| 放量滞涨 | 分歧加大 | 警惕高位派发 |

**情绪周期定位**：

```
冰点 → 修复 → 发酵 → 高潮 → 分歧 → 退潮 → 冰点
```

| 阶段 | 特征 | 量化参考（可按市况校准） | 操作 |
|------|------|---------------------------|------|
| 冰点 | 涨停少、炸板高、恐慌 | 涨停 ≤20 或 近5日分位≤20%；炸板率≥50%；连板高度≤2 | 试探仓，找错杀 |
| 修复 | 龙头出现、赚钱效应回升 | 涨停回升、炸板率下降、出现3板 | 试错加仓主线 |
| 发酵 | 主线明确、跟风积极 | 涨停≥60、连板高度抬升、主线涨停占比高 | 加仓主线 |
| 高潮 | 涨停潮、情绪亢奋 | 涨停≥100 或 近5日分位≥90%；连板高度见顶回落前一日 | 减仓兑现，不追 |
| 分歧 | 高位炸板、分化 | 高位股大面、炸板率升、量能仍在 | 只留核心，降仓 |
| 退潮 | 补涨乱、亏钱效应 | 连板高度连续下降、跌停增多 | 降仓/空仓，不接力 |

> 阈值为分析框架参考值；**以 §1.7 本机校准表（近 60 日分位）为准**，绝对数仅作辅助。未校准月份使用默认值时须在复盘中标注。

**输出**：大盘评分（强/中/弱）+ 风格标签 + 情绪阶段 + 建议总仓位区间。

---

## 步骤 3 · 板块与资金（找主线）

**目的**：资金是推动股价的直接动力；验证板块景气与持续性。

**资金**：
- 主力净流入 TOP10（行业 + 概念）——主指标
- 南向资金（港股联动时看）
- 北向：若终端仍提供历史/延迟数据可作辅助；实时数据不可得时按数据基建跳过，**不得用旧口径硬填**

**涨停结构分析**：

| 分析项 | 意义 |
|--------|------|
| 最高连板 | 市场短线情绪高度 |
| 热门涨停 | 板块号召力与辨识度 |
| 首板 / 2连 / 3连+ / 一字 / 换手板 | 启动质量与接力难度 |

**板块评估四问**：

1. **核心逻辑**是什么？（政策 / 业绩 / 事件 / 主题）
2. **持续性**如何？（故事长度、催化密度）
3. **内部分化**：龙头 / 跟风 / 补涨各是谁？
4. **炒作阶段**：启动 → 加速 → 分歧 → 退潮？

**中观验证**：PMI 分项、行业利润增速、领涨板块逻辑是否站得住、领跌板块风险是否出清。

**常见主线模板**：
- 科技 + 红利杠铃
- 出海出口链
- 内需消费
- 底部反转（困境反转）
- 高股息防御

**输出**：主线板块 1–2 条 + 备选 1 条 + 龙头/中军名单 + 板块阶段标注。

## 步骤 4 · 个股与技术面（精选股）

针对**自选股 + 持仓股 + 当日主线候选**做双重校验。

### 4.1 基本面快检

| 项 | 标准 / 动作 |
|----|------------|
| 盈利 | ROE、营收/利润增速、毛利率趋势 |
| 预期 | 未来 1–2 年增长空间与催化 |
| 地位 | 行业壁垒、竞争格局 |
| 公告 | 突发利空（退市、立案）、利好是否已兑现 |

### 4.2 技术面三维

| 维度 | 核心要点 |
|------|---------|
| **K 线形态** | 阴阳/光头/十字星；5/10/20/60 日均线；早晨之星/黄昏之星等组合 |
| **量价关系** | 放量突破、缩量回调、下跌缩量；识别主力意图 |
| **关键信号** | MACD/KDJ/RSI 金叉死叉；股价站上双红线（弱势拐点） |

### 4.3 量化共振诊断（技术评分，满分 100）

**前置硬门槛**：

| 门槛 | 条件 | 不过则 |
|------|------|--------|
| 流动性 | 20 日均成交额 ≥ 1 亿 | REJECT |
| 市场范围 | 剔除 688 科创、8 开头北交（默认） | 跳过 |

**评分表**：

| 条件 | 分值 |
|------|------|
| GMMA 多头排列（短组 > 长组） | +25 |
| GMMA 离散度 > 2% | +10 |
| 价格在云层上方 | +20 |
| 转换线 > 基准线 | +10 |
| TK 金叉 | +5 |
| 云层厚度 > 3% | +5 |
| ADX > 40 | +20 |
| ADX 30–40 | +15 |
| ADX 20–30 | +10 |
| 成交额 > 10 亿 | +5 |

**信号分级**：

| 信号 | 分数 | 操作 |
|------|------|------|
| **S** | 90+ | 强势观察，参考仓位上限 20%；仍须通过所有门禁 |
| **A** | 75–89 | 关注，参考仓位上限 10%；仍须通过所有门禁 |
| **B** | 60–74 | 观察，参考仓位上限 5%，等确认 |
| **C** | <60 | 放弃，仓位 0 |

> 实际首仓不得直接用参考仓位，必须按仓位公式用止损距离反推，并与账户熔断状态一起校验。

**动态止损**：

```
止损位 = max(云层下轨, 60EMA)
风险% = (现价 - 止损位) / 现价 × 100
```

若单笔风险 > 账户可承受上限，减仓或放弃。

**输出**：每只票一个「基本面结论 + 技术分 + S/A/B/C + 止损位 + 止损距离%」。

## 步骤 5 · 心态与纪律（修内功）

制定明日策略前，先反思今日交易：

| 检查项 | 问题 |
|--------|------|
| 情绪剥离 | 今日买卖是否被恐慌/贪婪驱动？ |
| 计划执行 | 是否按昨日清单操作？有无随意开仓？ |
| 扛单记录 | 有没有该止损未止损？ |
| 成功/失败 | 各写 1 条原因，归入体系 |

**强制动作**：每日写 3 行心得（做了什么 / 为什么 / 下次怎么改），每周日回顾一次。

## 步骤 6 · 策略制定与执行（定操作）

复盘的终点是**明日可执行的清单**，不是感叹。

### 6.1 操作基调矩阵

| 市场情境 | 策略基调 |
|----------|---------|
| 量能不足 / 抱团退潮 | 低吸回试探仓，禁止追高 |
| 趋势明朗 + 放量 | 适度提高仓位，顺势 |
| 风险偏好低 / 外围动荡 | 防御、内需消费、低估值、高股息 |
| 情绪冰点 + 主线未明 | 轻仓或空仓等待 |
| 任何情况 | 设仓位上限，避免过度集中单票/单板块 |

### 6.2 量化交易计划模板

**买入清单**（每行一只）：

| 字段 | 内容 |
|------|------|
| 标的 | 代码 + 名称 |
| 逻辑 | 属于哪条主线、为何入选 |
| 技术分 | S/A/B/C + 关键形态 |
| 买入区间 | 价格下限 ~ 上限 |
| 止损位 | 价格 + 触发逻辑 |
| 止损距离% | (买入中值 - 止损) / 买入中值 |
| 首仓比例 | **min(信号仓, 单票上限, 风险上限/止损距离%)** |
| 加仓条件 | 放量突破 / 回踩不破 xx |
| 第一止盈 | 价格 / 涨幅 + 减仓比例 |
| 第二止盈 | 价格 / 涨幅 + 清仓或持有 |

**卖出 / 止损规则**：

- 跌破关键支撑或动态止损位 → **无条件执行**
- 基本面恶化（业绩爆雷、监管）→ 立即评估是否清仓
- 达到目标位 → 分批止盈（如 1/3 → 1/3 → 1/3）
- 板块整体退潮 → 降仓，即使个股未破位

**工具辅助**：
- 震荡市：网格交易降成本
- 长赛道：基金定投平滑波动
- 组合：MVO / 风险平价 / VaR 做配置校验

**输出**：次日完整作战单（买什么、什么价买多少、什么价必须走）。

## 五维市场总结（复盘末尾固定栏目）

1. **整体市场**：强弱、风格、情绪阶段
2. **资金特点**：主力流向、南向（如需）、聚集板块；北向仅在数据可得时提及
3. **板块特点**：热门逻辑、轮动、持续性
4. **个股特点**：涨停/跌停/连板结构
5. **技术特点**：指数形态、支撑阻力、量价

## 复盘格言（按当日特点选/生成）

| 市场 | 格言 |
|------|------|
| 大涨 | 涨时重势，跌时重质 |
| 大跌 | 别人恐惧我贪婪 |
| 震荡 | 耐得住寂寞，守得住繁华 |
| 结构性行情 | 抓住主线，远离噪音 |
