# 08 · 输出格式契约（HTML 优先 / Markdown 次选）

## 8.1 优先级

| 优先级 | 格式 | 适用 |
|--------|------|------|
| **1（默认）** | **HTML 单文件报告** | 能写文件、能预览/交付时一律首选 |
| **2** | **结构化 Markdown** | 无法生成 HTML、或用户明确只要文本时 |
| — | 纯段落散文 | **禁止**作为唯一交付 |

无论哪种格式，**章节完整度、数据校验、来源标注、留空规则完全相同**。

## 8.2 HTML 交付硬约束

- **单文件**：全部 CSS（必要时极少量 JS）内联，不引用外网字体/CDN/图片外链
- **可离线打开**：双击本地 `.html` 即可完整阅读
- **A 股配色**：涨 `#ef232a`，跌 `#14b143`；缺失用灰底 `【缺失】`
- **信息密度**：一屏能抓住「大势 / 情绪 / 主线 / 明日动作」；细节可下滚
- **可执行优先**：首屏或紧跟五维之后给出「盘前作战单」卡片
- **免责声明**固定页脚
- 文件名建议：`StockMirror_复盘_YYYY-MM-DD.html`

## 8.3 报告章节结构（HTML / MD 相同）

```
0 页眉：标题 + 日期 + 作者/品牌 StockMirror · 股海镜鉴
1 【数据源状态】MCP 列表 / N / 模式 A|B|C / 风险提示
2 元信息卡片：可信度、熔断、校准日、冲突缺失
3 五维速览（摘要卡，可跳转到详细区）
4 步骤1 宏观与消息
5 步骤2 大盘与指数（含量价、情绪阶段、仓位闸门）
6 步骤3 板块与资金
7 步骤4 个股与技术（持仓 + 候选表）
8 步骤5 心态与纪律
9 步骤6 明日策略（买入/卖出/观察 + 基调 + 风险）
10 五维市场总结（展开）
11 格言 + 免责声明
```

## 8.4 完整度评分（自检）

交付前自检，低于 8 项通过则补齐或明确标注缺失原因：

| 项 | 通过标准 |
|----|----------|
| 数据源状态 | 有 MCP/模式说明 |
| 指数数据 | ≥3 个主要指数有涨跌或缺失说明 |
| 量能 | 成交额或量比定性有数字/来源 |
| 情绪 | 阶段结论 + 至少 1 个量化参考 |
| 板块 | 主线名称 + 阶段 + 至少 1 个资金/涨停证据 |
| 个股 | 持仓与候选逐只字段齐全或标缺失 |
| 风控 | 熔断状态 + 总仓位建议 |
| 策略 | 买/卖/观察三表或明确「今日无」 |
| 反向 | 至少持仓/候选含最差情景与证伪 |
| 来源 | 关键数字均带来源与可信度 |

## 8.5 HTML 布局建议（非强制样式，但是结构建议）

- 顶部：品牌条 + 日期 + 数据模式徽章（绿=互验 / 黄=单源 / 红=网络弱源）
- 摘要区：4–6 个 KPI 卡（大盘、量能、情绪、主线、仓位、熔断）
- 双栏（宽屏）：左=市场与板块，右=个股与作战单
- 表格：持仓/候选用紧凑表，字段对齐 §8.3
- 颜色：仅涨跌红绿 + 模式徽章；避免大面积高饱和底色干扰阅读

## 8.6 Markdown 次选结构

当输出 MD 时，严格按 @../templates/daily-checklist.md 章节顺序书写，  
并在文首保留「【数据源状态】」；作战单可直接嵌入或引用 pre-market-plan 结构。

## 8.7 禁止项

- 只有结论没有过程与数字
- 关键字段空白却无 `【缺失】` 标注
- 用估算/回忆填涨停数、成交额、净流入
- HTML 依赖外网资源导致离线打不开
- 用「格式问题」为借口砍掉六步中的任意步骤
