# 01 · 数据基建（步骤 0）

任何分析前必做。目标：保证「指数收盘、资金流向、涨跌停」等关键数据点可信。

**硬规则（不可跳过）**：
1. 先做 **MCP 连接检查**（§1.0）；发现没有金融行情 MCP 时，先主动提示并询问用户是否连接，或明确选择模式 C 降级继续。
2. 每一条数据必须经过 **准确性校验**（§1.2）。
3. **没取到的数据强制留空 + 写出提示**，禁止用估算、回忆、编造值填充。
4. 降级到网络搜索 / 弱源时，复盘结果必须显著提示「数据可能不准确」并引导用户连接 MCP。

---

## 1.0 MCP 连接检查（执行技能的第一步）

### 1.0.1 推荐行情数据 MCP 清单

Agent 启动本技能后，**必须先检测**当前环境是否已连接下列 MCP（名称匹配时忽略大小写/空格/常见别名）：

| 优先级 | MCP / 数据源名称 | 识别关键词（任一） | 主要用途 |
|--------|------------------|--------------------|----------|
| P0 | 同花顺 iFinD | `iFinD`, `同花顺`, `tonghuashun`, `10jqka` | 指数/个股 OHLCV、资金、财报 |
| P0 | 通达信 | `通达信`, `tdx`, `TDX`, `tdxpy` | 行情、技术指标、本地导出 |
| P0 | 东方财富（妙想） | `东方财富`, `东财`, `eastmoney`, `em`, `妙想`, `miaoxiang` | 资金流、涨跌停、板块、研报 |
| P1 | 万得 | `万得`, `Wind`, `wind`, `万得终端` | 机构级行情宏观、一致预期 |
| P1 | 腾讯自选股 | `腾讯自选股`, `自选股`, `qqstock`, `tencent stock` | 自选同步、行情快查 |
| P1 | Tushare | `tushare`, `Tushare`, `ts` | 日线/复权、财务、基础数据接口 |

> 其他**同类型**行情/复盘 MCP（雪球、akshare、choice、理杏仁等）可计入「备源」，但 **P0 至少 1 个**，且总可用行情 MCP **≥2** 才视为通过检查。

### 1.0.2 检查流程（必须按序执行）

```
1. 查看当前会话实际暴露给 Agent 的 MCP / 工具清单
2. 依据查询市场/指数/个股数据的能力识别金融行情来源，不能只凭名称或公网可达判定
3. 若没有任何金融行情 MCP：立即提示用户在宿主 MCP/工具设置中连接，并询问是否降级继续；等待用户选择
4. 用户选择连接时暂停行情分析，待配置完成后重新检查；明确选择降级继续时进入模式 C
5. 统计「已探活且独立的行情源数量」N，并校验逐来源样例证据
6. 分支：
   - ≥2 个已探活且独立的行情源、至少 1 个 P0 → 进入【模式 A · MCP 互验】
   - 仅 1 个已探活 P0 行情源 → 进入【模式 B · 单源 + 降级】，仅列观察候选
   - 无有效逐来源探活证据、仅有弱源或无 P0 → 进入【模式 C · 网络/弱源降级】，全文强制数据风险提示
```

若宿主未向 Agent 暴露 MCP/工具清单，不能断言当前未连接；应告知无法核实并请用户确认或提供可用工具信息。用户明确选择模式 C 后仍须遵守模式 C 的风险提示及禁止开仓规则。

**检查结果必须写在复盘文首**，格式：

```
【数据源状态】
- 已连接行情 MCP：____、____（N=2）
- 模式：A MCP互验 / B 单源降级 / C 网络弱源
- 建议：若 N<2，建议连接同花顺iFinD / 通达信 / 东财妙想 / 万得 / 腾讯自选股 / Tushare 中至少 2 个
```

### 1.0.3 三种数据模式

| 模式 | 条件 | 取数方式 | 复盘强制提示 |
|------|------|----------|--------------|
| **A · MCP 互验** | 已探活的独立行情源 ≥2，且至少 1 个 P0 | 主源 MCP + 备源 MCP 交叉验证 | 可标高可信（经互验） |
| **B · 单源降级** | 仅 1 个已探活 P0 行情源 | 单 MCP 取数 + 网络/官方源补核 | 文首提示；仅候选/观察，不作开仓依据 |
| **C · 网络弱源** | 可用行情 MCP =0 | 网络搜索最新公开数据 / 已安装同类技能 | **显著警告**（见下） |

**模式 C 强制警告模板**（必须出现在复盘最上方）：

```
【数据风险提示】
当前会话未连接足够的金融行情 MCP（同花顺 iFinD / 通达信 / 东财妙想 / 万得 / 腾讯自选股 / Tushare），或当前仅按用户选择使用弱源降级。
本次部分数据来自网络公开信息或弱源，**可能存在延迟、口径不一致或误差**，
结论仅供参考，**不作为开仓依据**。
请连接至少 2 个上述 MCP，以启用多源互验、提升数据准确性。
```

**模式 B 提示模板**：

```
【数据源提示】当前仅连接 1 个行情 MCP，关键数字未能完成双源互验。
建议再连接同花顺 iFinD / 通达信 / 东财妙想 / 万得 / 腾讯自选股 / Tushare 中任意 1 个。
```

**探活证据约定**：名称匹配和公开网络连通性都不等于 MCP 可用。脚本仅接纳宿主对每个来源的样例拉取结果，要求来源名、`independent_source_id`、成功状态、样例字段、有限数值样例和 ISO-8601 样例时间戳。可复制 `examples/probe-file.example.json`，将占位时间戳替换为实际拉取时间；`--probe` 仅作为网络诊断，不计入可用 MCP 数量。

## 1.1 数据源优先级

| 数据类型 | 主源（优先） | 备源 | 说明 |
|----------|--------------|------|------|
| 指数/个股 OHLCV | 通达信 MCP / 同花顺 iFinD MCP / 万得 MCP | Tushare、东财妙想、腾讯自选股 | 收盘价以交易所或主行情软件为准 |
| 实时/盘口 | 券商交易终端 / 通达信 | 东财妙想、腾讯自选股 | 盘中仅作参考，复盘以收盘数据为准 |
| 主力资金流向 | 东财妙想 / 同花顺 iFinD | 通达信、万得 | 口径可能不同，须注明来源 |
| 涨跌停/连板/炸板 | 东财妙想 / 涨停板复盘 | 同花顺、通达信 | 以「收盘仍封板」统计，不含盘中开板后回封 |
| 板块/概念资金 | 东财妙想 / 万得 | 同花顺 | 概念口径差异大，必须标来源 |
| 财务/估值 | 万得 / Tushare / 同花顺 | 巨潮、交易所披露 | 以定期报告为准 |
| 宏观/政策消息 | 财联社、证券时报、央行/统计局官网 | 新华社、券商研报、万得 | 以官方原文为准，媒体仅作线索 |
| 美股/港股/汇率 | 万得 / 雅虎财经、英为财情 | 同花顺美股、富途 | 时区换算注明 |
| 北向资金 | **见 1.5 节** | — | 实时口径已收紧，禁止按旧规则硬填 |

**执行层约定**：
- 工具链默认：复盘 → 筛选 → 技术 → 预测/全景 → 长线价值。
- **MCP 优先**；网络搜索仅作模式 C / 备源；本地脚本仅作补充。
- 单源缺失：字段留空并写「【缺失】源不可用」，**不得用估算值填充关键字段**。

## 1.2 互验与准确性校验（每条数据必做）

### 1.2.1 多源原则

关键结论涉及的数字（指数收盘、成交额、涨停家数等）至少 **2 个独立源一致** 才标「高可信」；仅 1 源时标「中」；源间冲突未解决时标「低」，并在结论旁注明冲突。能拿到第三源时优先用于仲裁。

| 冲突类型 | 处理 |
|----------|------|
| 收盘价差 <0.1% | 取主源，备注「备源略异」 |
| 收盘价差 ≥0.1% 或涨跌方向相反 | **暂停下结论**，换第三源；仍冲突则标「数据存疑」，该票/该指数降为观察，不进买入清单 |
| 资金流向口径不一 | 分别标注「东财口径 / 同花顺口径 / 万得口径」，不混用 |
| 消息真伪未核 | 只写「据报道」，不写进「已证实政策」 |
| 日期/交易日不一致 | 以交易所交易日历为准；非交易日数据不得混入当日复盘 |

### 1.2.2 单条数据校验清单

对每一个准备写入复盘的数字，依次核对：

- [ ] **字段完整**：代码/名称、日期、单位（亿/万/%）齐全
- [ ] **时间戳**：是否为当前交易日/最近收盘，有无过期
- [ ] **量级合理**：指数点位、成交额、涨跌家数是否在常识区间
- [ ] **符号方向**：涨跌、流入流出方向与文字描述一致
- [ ] **来源标注**：已写 `（来源：____，可信度：高/中/低）`
- [ ] **互验状态**：≥2 源一致 / 单源 / 冲突 / 留空

**任一项不过 → 不得作为结论依据；关键字段不过 → 强制留空。**

### 1.2.3 留空与禁止编造（强制）

**禁止**：
- 用「大概 / 约 / 估计 / 应该是」填补关键行情数字
- 根据历史印象推算当日涨跌停、成交额、净流入
- 将其他交易日数据伪装为当日
- 在未连接 MCP 时假装完成了双源互验

**未取到数据时强制写法**：

```
上证收盘：【缺失】未从可用源取得当日收盘价（原因：____）
涨停家数：【缺失】
主力净流入：【缺失】
—— 以上字段不得参与仓位与开仓决策 ——
```

**降级话术模板**（数据不足时强制使用）：

```
【数据可信度：低】
- 缺失项：______
- 原因：源不可用 / 源间冲突 / 披露规则变更 / 未连接 MCP
- 当前结论仅作方向参考，不作为开仓依据。
- 补齐路径：连接同花顺 iFinD / 通达信 / 东财妙想 / 万得 / 腾讯自选股 / Tushare 中至少 2 个后重跑
```

## 1.3 来源标注格式（全文强制）

复盘与规划中，凡引用具体数字或消息，必须在句末标注来源，格式二选一：

```
（来源：东财妙想 MCP，2026-09-10 收盘；可信度：高）
（来源：央行公告，2026-09-09；可信度：高）
```

多源一致时写：`（来源：东财妙想+同花顺 iFinD 一致）`。  
网络弱源写：`（来源：网络公开信息，YYYY-MM-DD；可信度：中/低，建议 MCP 复核）`。  
无来源的定性判断须标：`（判断，非数据）`。

## 1.5 北向资金等数据的现状说明（必读）

- 2024 年起，沪深港通**实时买卖额度与个股流向披露规则已大幅收紧**，盘中「北向实时净流入」在多数终端不可得或延迟。
- **禁止**在复盘中照抄旧模板的「今日北向净流入 XX 亿」作为关键论据；若终端无实时数据，写：`北向：实时数据不可得（规则变更），跳过该项`。
- 可替代观察项：南向资金（港股通）、离岸人民币、恒指相对强弱、外资重仓股相对收益。
- 步骤 3「板块与资金」以**主力资金流向 + 涨停结构 + 量价**为主，北向仅作可选辅助。

## 1.7 本机校准表（情绪阈值每月重算）

默认阈值（涨停≤20 / ≥60 / ≥100 等）会随市场体量与风格漂移失效。**每月首个周末**用近 60 个交易日重算一次，写入下表并覆盖默认值；盘前单眉注明「校准日：____」。

**校准步骤**：
1. 取近 60 日：每日涨停数、炸板率、最高连板、成交额。
2. 计算 P20 / P50 / P80 分位。
3. 映射到阶段阈值（可微调，写明理由）：

| 阶段 | 建议映射（默认，可改） | 本月实算值 |
|------|------------------------|------------|
| 冰点上界 | 涨停数 ≤ P20；炸板率 ≥ P80；连板 ≤ 2 | ______ |
| 发酵下界 | 涨停数 ≥ P50 且连板抬升 | ______ |
| 高潮警戒 | 涨停数 ≥ P80；或近 5 日成交额分位 ≥ 90% | ______ |
| 放量定义 | 当日额 / 20 日均额 ≥ 2.0 | ______ |

**规则**：
- 校准只改**阈值数字**，不改阶段名称与操作含义。
- 样本不足 60 日或处于极端单边行情时：保留上月值，并标「未校准」。
- 校准结果进盘前单与每日检查清单，避免各人用不同默认值自相矛盾。
- 校准所用行情数据同样受 §1.0 MCP 检查与 §1.2 校验约束；样本缺失则标「校准样本不足」。
