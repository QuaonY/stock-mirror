# 07 · 阈值速查

## 7.1 价值 / 财务阈值

| 指标 | 优秀 | 一般 | 危险 |
|------|------|------|------|
| ROE | >15% 连续 5 年+ | 10–15% | <10% |
| FCF/销售额 | >5% | 0–5% | <0% |
| 毛利率 | >40% | 20–40% | <20% |
| 负债/权益 | <1.0 | 1.0–1.5 | >1.5 |
| 安全边际 | >20% | 10–20% | <10% |
| 护城河评分 | 4–5 | 3 | 1–2 |
| 净利润率（长期） | >15% | — | 持续下滑 |
| ROA（长期） | >6–7% | — | 偏低 |

## 7.2 技术 / 情绪阈值

| 指标 | 参考 |
|------|------|
| 流动性门槛 | 20 日均成交额 ≥ 1 亿 |
| ADX 强趋势 | >40；中 30–40；弱趋势 20–30 |
| GMMA 多头 | 短组均线 > 长组；离散度 >2% |
| 云层 | 价在云上为强；止损参考云下轨与 60EMA 高者 |
| 连板高度 | 反映情绪天花板，连续降低警惕退潮 |
| 放量 | 相对 20 日均量 ≥2× 值得关注 |

## 7.3 情绪周期默认阈值（以本机校准表为准）

| 阶段 | 默认量化参考 |
|------|--------------|
| 冰点 | 涨停 ≤20 或近5日分位≤20%；炸板率≥50%；连板≤2 |
| 修复 | 涨停回升、炸板率下降、出现3板 |
| 发酵 | 涨停≥60、连板抬升、主线涨停占比高 |
| 高潮 | 涨停≥100 或近5日分位≥90% |
| 分歧 | 高位股大面、炸板率升、量能仍在 |
| 退潮 | 连板连续下降、跌停增多 |

## 7.4 交易成本参考（A股）

| 成本项 | 参考值 |
|--------|--------|
| 佣金 | 万 1.5–3，最低 5 元 |
| 印花税 | 卖出 0.05% |
| 过户费 | 双向约 万 0.1 |
| 滑点 | 短线 0.1–0.3% |

## 7.5 仓位与熔断速查

| 项目 | 参考 |
|------|------|
| 单票上限 | 15–20%（短线 10%） |
| 单板块上限 | 30–40% |
| 单笔风险 | 0.5–1.5% |
| 回撤 8% | 总仓减半，停新开 3 日 |
| 回撤 12% | 停新开 ≥1 周 |
| 连亏 3 笔 | 当日停开仓 |
| 月亏 10% | 剩余月总仓 ≤30% |
| 周亏 6% | 下周总仓降一档 |
| 止损距离 >12% | 放弃或等更好买点 |

## 7.6 DCF 参数速查

| 参数 | 参考 |
|------|------|
| 永续 g | 2.5–3%（衰退 2%） |
| 折现率 R 基准 | 10.5%（A股 10–12%） |
| 小市值/高杠杆/周期 | R +1–2% |
| 强护城河稳定 | R 可 9–10% |
| 高风险 | R 13–15% |
| 治理/流动性/政策折价 | 各 +0.5–1.5%（勿与 R 重复计） |
