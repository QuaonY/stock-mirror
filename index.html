StockMirror · 股海镜鉴

Stock = 股，Mirror = 镜鉴 · 版本 1.3.0 · 作者 Quaon

这是什么

A 股每日分析 → 复盘 → 规划 → 选股的可安装 AI Skill。含数据基建互验、六步 SOP、选股漏斗、仓位熔断、HTML 优先报告，以及生产级脚本门禁。

mode A/B/C 门禁 真探活 一键流水线 自动审计 Golden HTML

浏览器预览

  • Golden 复盘报告样例（应通过 report_lint）
  • SKILL.md
  • CHANGELOG
  • 硬门禁 G1–G8
  • 技能图标 icon.jpg

一键流水线示例

python scripts/run_pipeline.py \
  --available "tdx,ifind,eastmoney" \
  --probe-file examples/probe-file.example.json \
  --market-data examples/market-data.example.json \
  --tickers examples/tickers.example.json \
  --report examples/good-report.html

运行前请将 JSON 样例中的占位时间戳更新为真实拉取时间，并配置账户状态与风险画像。输出：state/pipeline/YYYY-MM-DD_summary.json + state/audit/

安装

  • WorkBuddy：先按 README 的安全打包步骤生成并上传 dist/StockMirror.zip
  • 本地技能目录：使用安全分发包，或复制不含本地状态数据的 Skill 文件到 ~/.claude/skills/stock-mirror/
本框架不构成任何投资建议。数据不足如实标注，禁止编造。
