# 反面示例（Bad Report）— 禁止照此输出

## 反面 1：模式 C 仍给买入清单

**错误**：未连 MCP，网络搜到模糊信息，直接写「明日买入 3 只」。  
**正确**：文首数据风险提示；只写观察池；引导连接 MCP。

## 反面 2：编造涨停家数

**错误**：`涨停大约七八十家吧。`  
**正确**：`涨停【缺失】未从可用源取得。` 或双源核验后写准确值+来源。

## 反面 3：熔断触发仍建议加仓

**错误**：账户回撤 10%，报告写「可对强势股加仓」。  
**正确**：circuit_breaker allow=false → 禁止新开仓；仓位减半。

## 反面 4：止损距离过宽仍凑仓位

**错误**：止损距离 15% 仍写首仓 20%。  
**正确**：distance>12% → 放弃或等更好买点（position_calc ok=false）。

## 反面 5：无来源的强结论

**错误**：`明日必涨，主线就是 AI。`  
**正确**：写清证据链（消息/资金/涨停结构）+ 来源 + 最差情景。

## 自检

跑：

```text
python scripts/report_lint.py 报告文件
```

FAIL 则必须修到 PASS。
