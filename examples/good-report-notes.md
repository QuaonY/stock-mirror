# 合格复盘报告要点（Golden Sample 摘要）

> 完整可渲染骨架见 @../templates/daily-report.html.md。  
> 本文件标注「合格长什么样」，供 Agent 对齐，避免骨架空转。

## 必须出现的块

1. 文首【数据源状态】：MCP 名单 + N + 模式徽章  
2. 若 mode=C：显著数据风险提示，且**无买入清单**  
3. 五维 KPI 卡：大盘/量能/情绪/主线/仓位/熔断  
4. 指数表：至少上证、深证、创业板；有来源或【缺失】  
5. 个股表：每行含技术分、S/A/B/C、止损、距离%、首仓%、最差情景  
6. 明日策略：买/卖/观察；每笔过五条件  
7. 页脚：格言 + 不构成投资建议  

## 合格数字写法（示例）

```
上证 +0.42%（来源：东财妙想+通达信一致；可信度：高）
两市成交额 9860 亿（来源：东财；可信度：高）
涨停 64 / 跌停 12 / 最高连板 5（来源：东财；可信度：高）
北向：实时数据不可得（规则变更），跳过该项
```

## 不合格写法（禁止）

```
今天大盘还不错，估计涨了零点几个点。   ← 无来源、模糊估算
主力净流入大概几百亿。                 ← 编造量级
上证【缺失】却仍给出「建议满仓进攻」。  ← 缺失仍下强结论
模式 C 仍输出 5 只「必买」。           ← 违反 G2 门禁
```
